This site, and a few personal projects, are built with Claude Code. I find the technology fascinating and really helpful - it's helped me do things I find necessary rather easily or things that are fun (a fantasy baseball draft prep that I should write longer about). The technology has its frustrations and quirks that I find difficult to navigate - it typically gets 90% of the way there and stalls. 

So something like this, on the back of all the other whole-computer agent releases, isn't surprising. I do think Anthropic needs to make a decision to de-silo the tools with Claude on MacOS. The different silos frankly don't make sense if they're all running the same model with slightly different permission parameters. Either way, not sure this is something I'll use but worth following along.
